# Sector Koochooloo visual usage

- Use the brand hero on boot, home and campaign entry points.
- Use mascot emotion artwork for reward/celebration moments, not as a constant background.
- Use rank badge artwork beside progression and achievement surfaces.
- Keep live account data (coins, XP, rank, missions) authoritative; visuals must never replace real values.
- Keep motion short and focused on reward, level-up, streak and splash moments.
- Prefer WebP for static UI artwork and lazy-load non-critical images.
- Preserve Telegram-safe contrast, touch target size and compact mobile layouts.
