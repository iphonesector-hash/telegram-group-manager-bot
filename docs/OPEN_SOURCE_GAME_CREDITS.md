# SectorLand open-source game credits

SectorLand's in-app arcade implementations are adapted for React, Telegram
WebView and the project's one-time score-session API. The original gameplay
references are MIT licensed:

- 2048 by Gabriele Cirulli: https://github.com/gabrielecirulli/2048
- Snake Game by Ramazan Cetinkaya: https://github.com/ramazancetinkaya/snake-game
- Memory Game by sen-ltd: https://github.com/sen-ltd/memory-game

The integrated versions use original SectorLand presentation, controls and
score submission code. External GitHub Pages games were removed because their
availability, WebView headers and score callbacks could not be guaranteed.
